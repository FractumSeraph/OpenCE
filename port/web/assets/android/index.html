Halo FS for Android

Halo: Combat Evolved on your phone, with online play
Download the app (.apk) The newest version. Needs Android 9 or later on a 64-bit phone. Native 64-bit build (experimental)

Both builds are the same app, so either one installs over the other and keeps your saves. Once installed, the app offers each new version itself when it starts.

Install it

  1. Tap Download the app on your phone and open the file when it is done.
  2. If Android asks, allow your browser (or Files app) to install unknown apps, then go back and tap Install.
  3. If Google Play Protect warns that it doesn't know the developer, tap More details, then Install anyway. The app isn't on the Play Store, so Play Protect has never seen it.
  4. Open Halo FS and tap Download the maps (about 1.8 GB, so use Wi-Fi). If you own the Xbox game, Choose disc image uses your own disc image instead.

If Android says the app can't be installed or conflicts with an existing package, an older copy signed with a different key is on the phone. Uninstall Halo FS first, then install again. Halo FS has its own app ID, so it installs beside the ChupathingyCE app and doesn't replace it.

How to play

  • In the menus, use the screen itself: tap an item to choose it, and swipe to move through a list. There are no on-screen buttons in the menus.
  • The on-screen controller appears once a match starts: a stick to move, buttons for the rest, and a swipe across the screen to aim.
  • In a match, Options (top right) changes the button layout, look sensitivity, vibration and gyroscope aiming, and imports maps. Hide (top middle) hides the controller; tap Touch to bring it back.
  • A Bluetooth or USB controller works too. Tap Hide to clear the screen while you use it.

Maps and online play

Custom Edition maps a server uses download on their own when you join. To add your own .map files, or .zip files containing them, open the touch controls' Options and choose Import maps, or hold the app's icon and choose Import Halo PC maps.

The app joins the same games as the browser version and the Windows and Linux versions, including FractumSnap and FractumSlayer.

Check the signature

Every release is signed with the same key. Its certificate's SHA-256 fingerprint is:

79:2A:A0:CD:51:3B:A0:22:0A:4E:0E:AD:65:08:33:A8:39:74:79:15:69:FA:49:57:9C:92:47:96:48:A8:85:99

To check a downloaded file on a computer with the Android SDK, run apksigner verify --print-certs halo-fs-android.apk. Its SHA-256 digest line should match the fingerprint above (without the colons).
